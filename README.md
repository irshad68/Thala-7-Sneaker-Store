# Thala 7 - Sneaker Store

## About

Thala 7 is a sneaker store website created as a CSS Mini Project.

The website contains:

- Landing Page
- Product Display Page
- Shopping Cart Page
- Payment / Checkout Page

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive CSS

## Features

### Landing Page
- Navigation bar
- Hero section
- Sneaker image
- Shop Now button
- Service overview

### Product Page
- Product image
- Product details
- Price and discount
- Quantity selector
- Add to Cart button
- Product image gallery

### Shopping Cart
- Product table
- Quantity controls
- Remove button
- Coupon section
- Order summary
- Pay Now button

### Payment Page
- Customer email
- Payment method selection
- Card details
- Country and ZIP
- Order summary
- Coupon
- Pay Now button
